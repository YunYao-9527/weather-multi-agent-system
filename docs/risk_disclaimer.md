# Risk Disclaimer

## 1. 系统边界
本系统是“强对流预警辅助决策系统”，不具备自动官方发布资格。

## 2. 数据风险
- 雷达瓦片代理与特征工程概率属于 proxy 输入，可信度低于正式业务产品
- 外部数据源可能出现时延、缺测、异常值

## 3. 模型风险
- 当前是多规则/多 Agent 融合原型，不是单一端到端气象数值模型
- 稀有灾种（如龙卷）样本可能不足，校准与评估稳定性受限

## 4. 决策风险控制
当触发以下任一条件时，系统将进入人工复核：
- 数据覆盖不足
- 冲突过高
- 关键源过期
- 代理依赖占比过高
- 降级模式触发

## 5. 合规与审计
- 每次推理必须保留 run_id
- 所有关键结论应可回放、可追溯、可复现
- 建议业务落地前完成本地与历史事件双重验证
